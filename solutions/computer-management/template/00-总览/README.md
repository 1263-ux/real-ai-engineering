# 电脑管理档案

## 目标

建立一套可回溯、可验证、可恢复的 Windows 电脑管理档案，重点覆盖开发环境、应用入口、缓存、容器、虚拟机和个人数据边界。

## 阅读顺序

1. `01-电脑现状\当前状态.md`
2. `02-软件与路径\软件位置索引.md`
3. `03-开发环境\开发环境说明.md`
4. `04-虚拟化与容器\Docker-WSL-VMware.md`
5. `05-使用指南\日常使用说明.md`
6. `06-维护日志` 与 `07-备份与恢复`

## 三条最高优先级规则

- 先取证，再规划，再操作，最后用真实入口验证。
- Docker Volume、WSL VHDX、VMware 磁盘、数据库、项目和个人数据不得当作普通文件清理。
- 删除、移动、修复、配置变更、安装卸载、管理员操作和虚拟化启停必须单独确认。
