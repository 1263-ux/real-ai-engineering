# 日常使用说明

## 每天开始工作

1. 确认网络、磁盘和关键开发命令可用。
2. 进入项目目录前确认当前分支和工作区状态。
3. 只启动本次工作需要的 Docker、WSL、VMware 或数据库组件。

## 启动项目

### 项目一

```powershell
Set-Location '<项目目录>'
<项目启动命令>
```

### 项目二

```powershell

<项目启动命令>
```

## 禁止直接操作

- 正在使用的数据库目录、Docker Volume、WSL VHDX、VMware 磁盘。
- 不明来源的服务、驱动、注册表项和文件关联。
- 没有备份、清单和回滚方案的删除或移动操作。

## 出现故障时

1. 保留错误原文、时间和触发命令。
2. 先做只读检查，不要立即重装或清理。
3. 读取最近维护记录和备份说明。
4. 明确目标、影响、备份和回滚方式后再申请修复。
