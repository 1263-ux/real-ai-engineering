# Computer-Management 管理框架模板

这是一个用于建立 Windows 电脑管理档案的通用模板，不包含任何特定电脑的状态、软件路径、用户名、日志、巡检 JSON、备份或个人数据。

## 目录

- `00-总览`：管理目标、阅读顺序和安全边界
- `01-电脑现状`：当前状态与已验证巡检状态
- `02-软件与路径`：应用、运行时、入口和路径索引
- `03-开发环境`：环境变量、命令、缓存和仓库说明
- `04-虚拟化与容器`：Docker、WSL、VMware 和虚拟磁盘登记
- `05-使用指南`：日常启动、项目操作和故障处理流程
- `06-维护日志`：维护记录、周期巡检报告和测试输出
- `07-备份与恢复`：备份清单、恢复说明和回滚记录
- `AGENTS.md`：供 Agent 执行初始扫描、建档、周期巡检和定时任务配置的完整说明

## 使用方式

1. 先填写 `01-电脑现状\当前状态.md`。
2. 再填写软件、开发环境和虚拟化目录索引。
3. 每次变更前记录备份、目标、风险、验证和回滚方法。
4. 巡检报告只记录证据，不自动删除、移动、修复或修改配置。
5. `clean` 技能不重复包含在本模板中；如需要，请由接收方单独安装或放入同级 `clean` 目录。

## 分发边界

本模板可以直接复制给其他人。填写实际电脑信息后，应仅在本机保存，不要把状态文档、维护日志、原始 JSON 或备份目录再次打包对外分发。
